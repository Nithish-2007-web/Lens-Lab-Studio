# LensLab Studio — Member 1 Contribution Pack

## Assigned role
**Backend Server & Routing**

## Files owned by this member
- `server.js`
- `routes.js`

## Responsibilities
1. Set up the Express application and PORT.
2. Configure express.json() middleware.
3. Mount all API routes.
4. Add the 404 handler for unknown routes.
5. Initialize the database before starting the server.
6. Explain route order, especially /cameras/summary before /cameras/:cameraId.

## Presentation topic
Project introduction, server architecture, middleware, route mapping, and server startup.

## Important: shared integration project
This ZIP includes the complete project source (excluding `node_modules`) so this member can understand dependencies and test the integrated application. The files listed under **Files owned by this member** are this member's primary contribution; the remaining files are shared reference/integration files.

## Run the project
1. Install Node.js (LTS recommended).
2. Open a terminal in the `LensLab-Studio` folder.
3. Run `npm install`.
4. Run `npm start`.
5. The server should start at `http://localhost:3000`.
